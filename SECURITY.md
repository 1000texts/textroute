# Security Policy

## Supported versions

This project is early-stage. Security fixes are applied on the default branch.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Email the maintainers (or use GitHub private vulnerability reporting if enabled on this repo) with:

- A description of the issue
- Steps to reproduce
- Impact assessment if known

We will acknowledge receipt and coordinate a fix before any public disclosure.
